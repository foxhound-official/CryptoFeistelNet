# CryptoFeistelNet

Учебный проект на Java с реализацией двух классических методов шифрования: **шифра Ришелье** и **сети Фейстеля**.

Проект выполнен в виде консольного приложения и предназначен для изучения принципов работы перестановочных и блочных методов шифрования, генерации ключей и выполнения раундовых преобразований.

> Проект является учебной реализацией и не предназначен для защиты реальных данных. Реализованные алгоритмы и схема работы с ключами не должны рассматриваться как современная криптографическая система.

## Возможности

### Шифр Ришелье

Реализована работа с решёткой Ришелье:

* ввод данных непосредственно из консоли;
* чтение данных из файла;
* генерация случайной решётки;
* изменение размера блока;
* сохранение решётки шифрования в отдельный файл;
* сохранение зашифрованных данных;
* расшифровка данных по сохранённой решётке;
* заполнение незанятых позиций случайными символами.

Размер блока задаётся пользователем. Для каждой строки решётки случайным образом выбирается одна позиция, куда помещается блок исходных данных. Остальные позиции заполняются случайными символами.

### Сеть Фейстеля

Вторая часть проекта содержит собственную реализацию раундовой схемы, основанной на сети Фейстеля.

Реализованы:

* шифрование данных из консоли;
* расшифровка данных из файла;
* генерация раундовых ключей;
* обратная генерация ключей для расшифровки;
* выполнение нескольких раундов преобразования;
* побитовое XOR-преобразование;
* работа с блоком размером 16 символов.

В текущей реализации используется 8 раундов, а исходный блок разбивается на четыре части по 4 байта.

### Основные классы

#### `Main.java`

Точка входа в приложение.

Содержит консольное меню для выбора алгоритма и операций.

Основное меню:

```text
--- Шифр Ришелье ---
1. Ввести свои данные
2. Данные из файла
3. Расшифровка данных
4. Установить размер блока
5. Переход к Фейстелю
```

После перехода к Фейстелю открывается отдельное меню:

```text
--- Шифр Фейстель ---
1. Ввести свои данные
2. Данные из файла
3. Расшифровка данных
4. NOTHING
0. Назад
```

#### `Richelieu.java`

Содержит реализацию шифра Ришелье.

Основные методы:

* `EncryptEnterData()` , шифрование введённой пользователем строки;
* `EncryptFileData()` , шифрование данных из файла;
* `DecryptData()` , расшифровка данных;
* `ChangeBlockSize()` , изменение размера блока;
* `random_str()` , генерация случайной строки для заполнения пустых позиций.

Сгенерированная решётка сохраняется в `alg.txt`, а результат шифрования в `data.txt`.

#### `Feistel.java`

Содержит реализацию сети Фейстеля.

Основные методы:

* `EncryptEnterData()` , шифрование введённых данных;
* `DecryptFileData()` , расшифровка данных из файла;
* `GenerateEncryptKey()` , генерация следующего ключа шифрования;
* `GenerateDecryptKey()` , генерация ключа для обратного преобразования;
* `Cryptor()` , выполнение раундового преобразования.

В классе определено 8 раундов обработки:

```java
private final int rounds = 8;
```

Размер используемого блока составляет 16 символов, которые разбиваются на четыре части по 4 байта.

## Принцип работы шифра Ришелье

При шифровании исходная строка разбивается на блоки заданного размера.

Например, при размере блока `2` строка может быть разделена следующим образом:

```text
HE LL O!
```

После этого создаётся квадратная матрица, размер которой зависит от количества блоков.

Для каждой строки матрицы случайным образом выбирается одна позиция:

```text
1 0 0
0 0 1
0 1 0
```

Выбранные позиции содержат реальные блоки исходного сообщения.

Остальные позиции заполняются случайными символами:

```text
HE x1 x2
x3 x4 O!
x5 LL x6
```

Полученная последовательность сохраняется как зашифрованное сообщение.

Для расшифровки используются:

1. размер блока;
2. сохранённая решётка;
3. зашифрованная строка.

По позициям со значением `1` исходные блоки извлекаются обратно.

## Принцип работы сети Фейстеля

В реализации используется блок размером 16 символов.

Он разбивается на четыре части:

```text
z1 = 4 байта
z2 = 4 байта
z3 = 4 байта
z4 = 4 байта
```

Ключ состоит из 4 байт.

Для преобразования ключа используются операции перестановки и инверсии отдельных байтов:

```text
final_key[0] = key[3];
final_key[1] = ~key[0];
final_key[2] = key[1];
final_key[3] = ~key[2];
```

Обратное преобразование выполняется методом `GenerateDecryptKey()`.

Основное раундовое преобразование использует операцию XOR:

```text
data XOR key
```

В коде предусмотрено несколько раундов обработки с последовательным изменением ключа.

## Файлы данных

В репозитории присутствуют несколько файлов, используемых в качестве входных и выходных данных.

### `alg.txt`

Содержит параметры решётки Ришелье.

Первая строка определяет размер блока, последующие строки представляют матрицу:

```text
2

001000
000001
000010
100000
000001
```

### `data.txt`

Содержит пример зашифрованной строки, полученной при использовании шифра Ришелье.

### `b.txt`

Содержит пример бинарных данных, полученных при работе с реализацией Фейстеля.

## Запуск

Для запуска проекта потребуется:

* Windows, поскольку исходный код содержит абсолютные пути Windows;
* JDK 16 или совместимая версия Java;
* IntelliJ IDEA либо другая IDE с поддержкой Java.

Проект содержит конфигурацию IntelliJ IDEA и модуль:

```text
labs.iml
```

Версия JDK, указанная в конфигурации проекта:

```text
OpenJDK 16
```

### Запуск через IntelliJ IDEA

1. Клонировать репозиторий:

```bash
git clone https://github.com/foxhound-official/CryptoFeistelNet.git
```

2. Открыть проект в IntelliJ IDEA.

3. Убедиться, что выбран JDK 16.

4. Запустить:

```text
src/com/company/Main.java
```

5. В консоли появится главное меню приложения.

## Работа с файлами

В исходном коде используются абсолютные пути, например:

```text
E:\Documents\4.1\Безопасность\labs\Lab2\
```

Поэтому на другой машине эти пути необходимо изменить.

В частности, пути используются при:

* чтении входных файлов;
* сохранении `alg.txt`;
* сохранении `data.txt`;
* сохранении зашифрованных данных Фейстеля в `b.txt`.

Без изменения этих путей приложение может не найти необходимые файлы или не сможет сохранить результат.

## Ограничения текущей реализации

Проект создавался как учебная работа, поэтому имеет ряд особенностей:

* используются жёстко заданные пути к файлам;
* отсутствует универсальная настройка каталога данных;
* работа с файлами рассчитана на конкретную структуру окружения;
* реализация Фейстеля является собственной учебной схемой, а не реализацией стандартизированного современного шифра;
* ключ Фейстеля имеет фиксированный размер;
* блок Фейстеля имеет фиксированный размер 16 символов;
* часть меню Фейстеля содержит экспериментальный пункт `NOTHING`;
* в исходном коде присутствует закомментированный экспериментальный код;
* обработка кодировок и байтов ориентирована на Windows-1251.

Поэтому проект лучше рассматривать как лабораторную реализацию алгоритмов, а не как готовую криптографическую библиотеку.
